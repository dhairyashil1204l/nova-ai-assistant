# Nova AI Assistant 🤖

An AI assistant built using Streamlit and Google Gemini API.

## Features
- User interaction through Streamlit UI
- Gemini AI powered responses
- Secure API key management using .env
- Real-time AI response generation

## Tech Stack
- Python
- Streamlit
- Google Gemini API
- python-dotenv
